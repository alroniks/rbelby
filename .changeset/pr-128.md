**Bump preline from 4.1.2 to 4.2.0**

Bumps [preline](https://github.com/htmlstreamofficial/preline) from 4.1.2 to 4.2.0.
<details>
<summary>Release notes</summary>
<p><em>Sourced from <a href="https://github.com/htmlstreamofficial/preline/releases">preline's releases</a>.</em></p>
<blockquote>
<h2>v4.2.0 - New components, 10+ framework guides, and quality improvements</h2>
<p>Adds Marquee components, expands Stepper and Spinner examples, adds 13 framework guides, and includes Tailwind CSS v4.2.x support plus dropdown and scrollspy fixes.</p>
<p><strong>New Components &amp; Improvements</strong></p>
<ul>
<li>Customization: <a href="https://preline.co/docs/colors.html">Tailwind CSS v4.2.x new color palettes added to all components.</a></li>
<li>Navigations: Expanded the <a href="https://preline.co/docs/components/stepper.html">Stepper</a> docs with new vertical examples for static, linear, white, solid, and dynamic linear variants.</li>
<li>Components: Added new <a href="https://preline.co/docs/components/marquee.html">Marquee</a> components with text ticker, logo marquee, vertical, 3D, finance ticker, and card marquee examples.</li>
<li>Components: Expanded the <a href="https://preline.co/docs/components/spinners.html">Spinners</a> docs with new throbber, ring, pulse dot, wave, bars, terminal, blinking caret, shimmer text, loading dots, and ellipsis examples.</li>
<li>Docs: Added a new <a href="https://preline.co/docs/components.html">Components</a> index page to help users browse all Preline docs by category.</li>
<li>Docs: Added specific Preline UI JavaScript guides for <a href="https://preline.co/docs/guides/html-vite.html">HTML + Vite</a>, <a href="https://preline.co/docs/guides/hugo.html">Hugo</a>, <a href="https://preline.co/docs/guides/express.html">Express</a>, <a href="https://preline.co/docs/guides/react-vite.html">React + Vite</a>, <a href="https://preline.co/docs/guides/nextjs.html">Next.js</a>, <a href="https://preline.co/docs/guides/remix.html">Remix</a>, <a href="https://preline.co/docs/guides/vuejs.html">Vue.js</a>, <a href="https://preline.co/docs/guides/nuxtjs.html">Nuxt.js</a>, <a href="https://preline.co/docs/guides/angular.html">Angular</a>, <a href="https://preline.co/docs/guides/emberjs.html">Ember.js</a>, <a href="https://preline.co/docs/guides/svelte.html">Svelte</a>, <a href="https://preline.co/docs/guides/solidjs.html">SolidJS</a>, and <a href="https://preline.co/docs/guides/qwik.html">Qwik</a>.</li>
</ul>
<p><strong>Updates</strong></p>
<ul>
<li>Updated: Tailwind CSS to v4.2.x</li>
<li>Updated: Replaced legacy aspect-ratio plugin usage with native Tailwind CSS aspect-ratio utilities and removed the <code>@​tailwindcss/aspect-ratio</code> dependency.</li>
</ul>
<p><strong>Fixes and Improvements</strong></p>
<ul>
<li>Fixed: Preserve selected remote options in dropdown across searches in tags mode and fix crash when re-selecting an option after a subsequent search. [[Issue <a href="https://redirect.github.com/htmlstreamofficial/preline/issues/752">#752</a>]](<a href="https://redirect.github.com/htmlstreamofficial/preline/issues/752">htmlstreamofficial/preline#752</a>)</li>
<li>Fixed: Fix browser back button navigating away from page instead of returning to previous section by replacing replaceState with pushState and adding a popstate listener in scrollspy. [[Issue <a href="https://redirect.github.com/htmlstreamofficial/preline/issues/749">#749</a>]](<a href="https://redirect.github.com/htmlstreamofficial/preline/issues/749">htmlstreamofficial/preline#749</a>)</li>
</ul>
<h2>v4.1.3 - Updated documentation for frameworks</h2>
<p><strong>Fixes and Improvements</strong></p>
<ul>
<li>Fixed: Documentation updated according to the latest Preline release. [[Issue <a href="https://redirect.github.com/htmlstreamofficial/preline/issues/746">#746</a>]](<a href="https://redirect.github.com/htmlstreamofficial/preline/issues/746">htmlstreamofficial/preline#746</a>)</li>
<li>Fixed: Add wildcard exports for <code>css</code>, <code>src</code>, <code>dist</code> and <code>variants.css</code> to support bare specifier imports.</li>
</ul>
