# Spec [010]: Community (Clubs, Riders & Journal) MVP

**Feature ID**: `010-community-mvp`

## Overview

Launch the community-focused sections of the site, introducing Clubs, individual Rider profiles, and Journal articles.

## Implementation Tasks

- [x] **Create `pages/clubs/index`**: Create `pages/clubs/index.astro` displaying a grid of club cards.
- [x] **Create `pages/clubs/[club]`**: Create `pages/clubs/[club].astro` displaying individual club details.
- [x] **Create `pages/riders/[rider]`**: Create `pages/riders/[rider].astro` to display individual randonneur statistics and history.
- [x] **Create `pages/riders/index`**: Create `pages/riders/index.astro` displaying a searchable directory of riders.
- [x] **Create `pages/journal/index`**: Create `pages/journal/index.astro` to list articles.
- [x] **Create `pages/journal/[slug]`**: Create `pages/journal/[slug].astro` to render individual article markdown.
